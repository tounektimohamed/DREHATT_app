## 📖 Overview

**DREHATT** is a geospatial and mapping application built with Flutter. It renders GeoJSON layers on interactive maps with offline support via MBTiles.

## ✨ Features

- Interactive maps with flutter_map
- GeoJSON layer loading
- Offline maps using MBTiles
- Draggable markers & map drawing tools
- Firebase authentication & storage
- Dark / light theming


## 🛠 Tech Stack

Flutter, Dart, Leaflet, Firebase.

## 🚀 Getting Started

```bash
git clone <repo-url>
cd <repo>
flutter pub get
flutter run
```

> Requires the [Flutter SDK](https://docs.flutter.dev/get-started/install) (stable channel).
